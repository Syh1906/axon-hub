# API Key 自助用量

管理员在「项目 → 密钥分组」可点击名称或备注旁的铅笔直接编辑，使用行内开关启停分组。点击额度可设置、增加或取消该周期限额；已用额度与刷新周期保留。点击有效期可快捷顺延、自选时间或设为永不过期，保存后生效，续期不会自动启用分组。批量修改继续使用「批量管理」，周期设置和额度重置在行末菜单的「高级设置」中。

若提交结果已收到但列表刷新失败，使用弹层中的「刷新」重新读取，无需再次保存。若请求结果未知，可暂时关闭并从页面恢复原批次；恢复不会重复执行已成功的操作。

在管理端登录页点击「使用 API Key 查看用量」，或直接打开 `/self-usage`。输入 **user** 或 **personal** 类型的 API Key 即可查看用量，无需管理端账号。其他类型的 Key 不适用。

登录后显示 Key 名称与系统时区；可切换中英文和主题。Key 只保存在当前浏览器标签页的会话存储中；同一标签页刷新后可继续查看，关闭标签页或点击「登出」会结束页面登录。登出不会吊销 API Key；需要撤销 Key 时，请在管理端操作。

可选今天、昨天、近 7 天、近 30 天、本月，或自定义起止日期（首尾日期都计入，最多 90 天）。所有日期和请求时间均按页面显示的系统时区计算；每日趋势按请求创建日归属。汇总提供成功和失败请求数、Token、成本，并可按模型查看；日志可按模型与状态筛选并分页。进行中的请求可出现在日志中，但不计入成功或失败统计。失败或取消的请求只要留下了用量记录，其 Token 和成本仍计入统计。一个请求即使有多条用量记录，也只计一次请求数。

请求日志增加调用方列，并展示 ID（原始状态、流式/非流式）、模型、Token（总计、输入、输出和推理）、读缓存（数量与命中率）、写缓存（数量与写入率）、成本、耗时、创建时间。耗时仅对已完成请求显示：流式请求包含首字与总耗时，非流式请求只显示总耗时；创建时间标注系统时区。成本使用系统币种；悬浮或聚焦成本金额可查看输入、输出、读缓存、写缓存（含 5m/1h 变体）等已落库分项、折算每百万 Token 单价、阶梯，以及基础合计、倍率与合计。基础合计与倍率始终显示，1 倍时为「×1」、基础合计等于合计；多条用量记录按分项合并，各记录倍率不一致时倍率显示「混合」、基础合计显示「-」。

汇总、每日与按模型统计中，没有用量记录时成本为 0；用量全部未定价时显示「—」；部分未定价时显示已知成本并标注未定价记录数，实际零价仍显示 0。请求日志与管理端请求列表一致：没有用量记录的请求，Token、缓存与成本列显示「-」；用量全部未定价时成本显示「-」且无悬浮。

默认展示**当前 Key、所属项目中来源为 API 的请求**。如果 Key 属于分组，可切换到「分组用量」，查看同一项目内当前组员的合计、趋势、模型明细和日志；调用方显示密钥名称与分组名称。移组后，后续统计查询会同时更新所属分组标签；仅切换日志状态、模型或页码时，若检测到归属变化，也会同步重取汇总和日志，保留当前日志筛选。切换范围时不沿用旧组缓存。分组归属由服务端根据输入的 Key 确定，不接受任意分组编号。无分组时不显示切换入口；两种范围都排除 Playground 和测试请求。日志不展示请求与响应正文、渠道、上游模型或错误详情。若查询或登录太频繁，页面会提示稍后重试；访问受限的 Key 也无法登录。

## 管理密钥分组

项目管理员在项目侧栏的“密钥分组”页面管理使用者分组；API 密钥页面保留全量密钥视图。分组不是登录账号，不改变成员的权限类型与路由。分组名称在项目内唯一，密钥默认可不分组。只有项目管理员可改归属，因为加入分组会开放整组用量查看。删除分组将成员转为未分组；目标重名时整行拒绝，不会删除密钥或请求。

密钥列表支持分组多选筛选和「默认分组」。默认分组按当前用户、当前项目保存在本机浏览器，保存后立即应用，下次进入页面也会应用；临时筛选不覆盖默认值，取消不保存，清空默认值表示不过滤。可以单独选择「无分组」。已保存但被删除的分组仍以「不可用分组」显示，可手动移除后保存，不会自动放宽筛选。分组选项使用查询缓存，增删改后刷新；移组后相关密钥、请求和统计查询也会刷新。

统计采用**当前归属**：例如某密钥从 A 组移到 B 组，该密钥保留的历史用量也全部计入 B 组；取消分组后不再计入分组统计。这样只需在密钥上保存一个分组编号，无需为每条请求或用量另存快照，也无需移动历史记录。代价是无法查看“请求发生时属于哪个组”。无分组不出现在分组统计和排行榜中，单密钥用量仍然保留。

请求、密钥选择项与统计中的密钥名称采用「密钥名称 · 分组名称」；无分组时使用「密钥名称 · 用户名称」。备份 1.6 在选择密钥时同时保存分组对象，包括空组、备注和启停状态，恢复时按目标项目和分组名称关联，并沿用密钥的跳过／覆盖／报错策略。可读取旧格式；旧格式没有分组状态时沿用原有默认启用行为。旧程序不接受 1.6，避免静默丢失停用状态。

### 密钥名称与分组

密钥名称在同一项目、同一分组内唯一；未分组密钥构成单独的命名范围。不同分组以及分组与未分组之间可以同名。移组或删除分组导致目标范围重名时会拒绝操作并保留原归属，请先改名或调整目标。停用、归档不释放名称。管理 OpenAPI 按名称定位时可指定 `groupRef`（0 表示未分组）；存在跨组同名时必须指定分组或使用密钥 ID，不能仅按名称选择。

### 分组管理与批量分发

分组行展示备注、可见密钥数量、有效期和五周期共享额度（可用／上限）。可以按分组、备注或密钥名称搜索，筛选状态和排序；成员在展开时独立分页加载。“未分组”仅是整理入口，没有共享额度、组启停或删除操作。具备当前项目 `read_api_keys` 时可读取项目内个人密钥；编辑仍需要 `write_api_keys`，不能跨项目读取。

停用分组会阻止成员发起请求，但不修改每把密钥自身的启停状态。恢复分组后，原来单独停用的密钥仍停用。分组限制与密钥独立限制同时生效；移组不会搬走已经计入旧组预算账本的费用。用量统计仍按当前成员关系汇总，不能当成历史预算扣账。

组内单密钥可直接点击名称、有效期和五周期额度修改，启停使用行内开关；「设置」直接填写保存，无需先勾选要修改的字段。用量成本旁提供整体缓存命中率，悬浮或键盘聚焦可查看各模型的缓存读取／输入词元及命中率。

- **单条创建**：填写完成后直接添加，服务端校验名称冲突并保留失败草稿；不需要手动预检。创建分组时可同时创建初始密钥；组内添加密钥会固定当前分组。可选配置模板、独立预算、有效期与 IP 限制，默认个人类型，服务账号必须明确填写 scopes。成功结果先保留供复制，点击“继续添加”才清空名称、保留当前组和密钥配置。
- **批量建组**：粘贴一行一个名称、Excel 多列，或导入 CSV；先核对列映射再追加。共享设置可包括预算与初始密钥集。每行可单独覆盖、复制、移除或恢复沿用；修改公共值不会覆盖已单独设置的行。
- **批量加钥**：可以为多个目标分组生成同一套名称，也可逐行指定分组、名称和模板。重复生成仅补充缺少的组合。每次最多提交 100 行；每个新分组最多包含 100 把初始密钥。
- **批量管理**：先选择分组或密钥；切换对象会清空选择。默认全选只选当前页，跨页选择按 ID 保留，切换项目会清空。分组支持备注、启停、共享预算／有效期和删除；密钥支持模板、独立预算／有效期、IP、移组、启停与归档。只修改勾选字段，清空备注、移除限制或永不过期需要明确选择。

先检查冲突与设置，再明确提交“已选且有效”的行；无效行保留待修正。多列导入统一按整份清单的列映射处理，某行缺少分组列或留空都会拒绝，未分组须明确填写“未分组”。单列密钥清单仅在明确选择一个目标时继承该目标（可选择未分组）；多目标请使用生成清单，或逐行提供分组列。新分组、初始密钥、模板与预算按行一起成功或回滚。请求结果未知时查询原批次，避免重复创建。恢复窗口可以暂时关闭，页面保留恢复入口；在核对原批次前不会覆盖它提交另一批次。浏览器存储不可用时，在当前页面内仍保留原请求；会话存储可用时，刷新同一标签页后也能恢复。恢复并不撤销已经成功的行。

结果中的密钥默认遮盖。复制单行、复制选中结果、导出选中 CSV、复制 API 地址和自助用量入口都由操作人主动触发。发生并发修改时，需关闭表单并刷新后重新核对；修改预算不会重置已用或暂占，额度重置仍使用独立的预算重置入口。
