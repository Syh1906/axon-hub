## 行为与实现

- 名称和备注共用就地两字段表单，备注可清空，取消不提交；独立箭头展开成员。
- 行内开关启停，提交期间防重复操作。分组启停沿用原有权限和成员状态语义。
- 五个额度周期可单独设置、增加或取消，金额计算使用 Decimal；保存只提交当前周期，已用、暂占、刷新方式和其他周期不重置。
- 有效期支持 +7天／1个月／3个月／1年、自选日期时间、永不过期；快捷项先回填再保存。未过期顺延、已过期从现在起算，续期不启用停用分组。
- 普通模式批量按钮并入搜索栏；批量预检和逐行结果保留。行末菜单保留高级预算和原管理操作。
- 复用 `useSubmission` 的权限、版本检查、操作编号和原请求恢复；成功回读完成后关闭弹层。服务端拒绝保留输入，未知结果通过原请求恢复，不重复生成请求。

主要文件：`frontend/src/features/key-groups/quick-edit.tsx`（new）、`quick-edit-date.ts`（new）、`quick-edit-date.test.mjs`（new），以及 `index.tsx`、中英分组文案。无需后端、schema 或 data migration 变更。

## 独立复审与主执行者自检

独立 subagent 使用用户指定的 `gpt-6.1-sol / max`，先读取项目规则与 `axon-frontend-iteration`，只沿本次改动和直接调用链审查；没有扩大到全库治理。以下问题已修复并由独立审查者复核：

- 夏令时跳过的本地时间不再悄悄改为另一时刻，直接提示无效；无修改保存保留原有秒数及重复小时对应的原始瞬间。校验和保存共用解析结果。
- 调低额度后的可用金额预览取下限 0，与服务端一致。
- 保存回执成功但列表读取失败时保留编辑弹层，显示待刷新状态；只重试读取，不重发保存。只将分组列表读取作为必需回读，其他关联查询不会升级为阻塞条件。
- 未知结果允许稍后恢复；即使原行在请求期间因翻页卸载，页顶仍出现恢复入口。恢复失败不自动收起，快捷恢复成功清除残留入口。
- 弹层通过 `aria-labelledby` 关联实际标题。
