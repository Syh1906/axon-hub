## 发现及修复

| 问题 | 原因与修正 |
| --- | --- |
| 批量填优先级 11 后原编辑不能保存 | 新入口允许 100，原表单上限 10；共享 0–10 常量并使用整数。 |
| 多标签零匹配可能显示全部 | Ent 忽略空 `idIn`；未就绪／零匹配禁发列表查询并明确空分页，摘要失败显示可重试错误。 |
| 编辑渠道标签后多选结果陈旧 | 摘要缓存不属于渠道失效范围；摘要和标签查询统一使用 channels 前缀，并同步直接失效调用。 |
| 批量追加可能遗漏深层原条件 | 回读只取两层子条件；MODELS_QUERY 补全后端允许的第三层组及叶节点。 |
| 同渠道多个模型预览重复 React key | 每条连接都用 channel.id；预览按渠道合并并按 requestModel 去重，不改实际关联规则。 |

模型列表现已显示真实 matchType 的精确／前缀／后缀／正则徽标。截图中的“供应商”按钮是已有的供应商分类栏显隐开关，本轮没有重设计该控件。
